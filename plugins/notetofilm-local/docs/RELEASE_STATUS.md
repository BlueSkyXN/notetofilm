# 0.1.0 交付与验证记录

日期：2026-10-19。此版本为 NoteToFilm-local 的首版本地实现，位于父仓库 `plugins/notetofilm-local/`。版本号与父 Web 应用独立。

## 已实现

- 七个 Skill：工作流编排、材料整理、导演分镜、图片、视频、音频、合成。
- 独立安装环境、自包含技能说明、portable plugin.json 和源码打包脚本。
- CLI 项目初始化、素材导入、正式分镜、计划、状态、选择、单独生图/视频/配音、合成。
- 六个原样模型 ID，模型、公司路由、协议和能力声明分离。
- openai-images 的普通生图和有序多图参考；ark-video 和 gemini-veo 的明确模式映射、提交、查询与下载。
- 实际素材登记、输入变化判断、保留历史、单动作重做、远端任务恢复、下载失败续做、提交结果不明时不重复 POST。
- Edge TTS 可选依赖、实际音频长度和服务返回边界、字幕与读法文本记录、可配置代理。
- FFmpeg 图片/视频混排、裁剪、明确的末帧延长、四种声音策略、真实时间表、字幕文件/烧录、MP4。

## 验证结果

在 Linux、Python 3.12.14、可执行 FFmpeg/ffprobe 环境中运行：

```bash
PYTHONPATH=runtime python3 -m unittest discover -s tests -v
```

**59 项测试全部通过**：公司协议 30 项，Edge 流处理 2 项，媒体与真实合成 5 项，技能安装/打包 6 项，项目编排/恢复 16 项。测试没有调用公司模型或产生付费生成。

七个技能全部通过 SKILL.md 元数据校验。安装测试覆盖独立环境、带空格目录、源码移除后继续运行、同名技能冲突和升级失败恢复。

独立首次使用验证从 workflow Skill 开始，通过真实 CLI 导入四份媒体，合成两镜 2.2 秒的 H.264/AAC 视频；只将第二镜的声音策略由 mix 改为 edge_tts 后再合成，原素材哈希和数量保持一致，两版视频帧一致，第二镜声音实际发生变化。两次成片分别保留。已修复这个验证中发现的“独立成片后 status 仍显示未完成”问题。

`examples/demo/output/video.mp4` 是另一份已实际编码的 4.6 秒样片：640×360、15 fps、H.264/AAC。其字幕和声音明确标为技术测试素材。

## 当前范围

转场为切换；没有程序化复杂转场、口型修改或人声分离。准确标题和图表先制作成输入图片。局部修改复用原始媒体；合成阶段重新编码整条影片，没有逐帧缓存。公司自定义协议若改变字段或上传流程，需要追加协议适配代码。

跨客户端交付采用明确的技能目录安装；本轮实测平台是 Linux，不把它表述为各客户端原生插件安装或 macOS/Windows 都已实测。未来集中平台可沿用模型路由、适配接口和项目记录，本版本没有部署集中平台服务。
