# 视频片段制作

1. 读 [本机入口](references/runtime.md)、[命令](references/commands.md)、[项目格式](references/project-format.md)。独立生成片段可以没有正式分镜，但保留项目与动作结果。
2. 读取动作目标、画面内容、参考素材与期望时长。用 `ntf routes --config FILE` 确定实际通道与支持模式，读 [模式与公司通道](references/modes-and-company.md)。
3. 只有文生视频时不制造无用参考图。图生视频等待所选图片。首帧、尾帧分别传入；多张外观参考不得冒充首尾帧。
4. 为需按讲述节奏制作的片段先取得实际配音时长，再选择通道允许的片长。独立场景素材可先生成，合成时再按实际文件安排。
5. 在已有工作流中执行 `ntf run` 的具体动作；单项任务使用 `ntf generate PROJECT --request FILE --config FILE`。所有参考文件先进入项目。
6. 提交后保留动作与返回的任务 ID，按 [恢复方法](references/resume.md) 查询已有任务。取得视频文件后登记真实时长、尺寸和音轨情况。
7. 返回片段文件、素材 ID、使用的生成模式，以及尚未完成的任务。完整成片交给编排与合成 Skill。

不擅自更换公司通道、使用厂商官方端点、删除参考图或改变关键动作来绕过限制。已明确要求的模式不受支持时，说明该模式缺少什么，保留已经完成的其他工作。
