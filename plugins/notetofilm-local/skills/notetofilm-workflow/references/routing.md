# 从现有输入开始

| 当前输入或修改 | 进入哪一步 |
|---|---|
| 只有原材料，要求完整视频 | prepare → direct → 所需媒体 → compose |
| 已有讲解稿，只配画面 | direct 保留指定旁白 |
| 已有正式分镜 | 所需 image、video、audio，再 compose |
| 已有图音和顺序 | compose |
| 只换图片 | image 或导入，再选择与合成 |
| 只改旁白 | direct 更新，再 audio 和时间安排 |
| 修改核心事实或受众 | 先调整材料与导演，再判断媒体范围 |
| 继续项目 | 读取 status、ready，处理仍需完成的动作 |

每次交接只需项目位置、目标、固定镜头范围与用户约束。其他阶段读取正式文件。不要把阶段读取解释成启动另一套常驻程序；当前 Agent 可以连续完成。
