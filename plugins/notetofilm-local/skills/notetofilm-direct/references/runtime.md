# 定位本机运行代码

本文件在源码包中只包含通用说明。使用 `scripts/install.py` 安装后，安装器会把本机 `ntf` 命令、Python 环境与同套件技能的准确位置写入本文件。

已经通过其他方式安装运行包时，使用该安装过程给出的命令路径并执行 `ntf install-info`。不要遍历用户目录寻找其他插件，也不要依赖 `../../runtime/` 或同胞 Skill 的相对路径。

没有可用运行命令时，可以先完成材料与导演任务；媒体生成和出片需要完成运行包安装及相应工具接入后继续。不要把仅写出计划描述为已生成视频。

当前配置目录未包含公司凭据或已确认协议。用 `ntf config-init FILE` 生成样例，用 `ntf routes --config FILE` 阅读实际状态，再使用已明确配置的通道。模型 ID 是不透明的公司标识，不根据名称猜测官方端点或能力。
