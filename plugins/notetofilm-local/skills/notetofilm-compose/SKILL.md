# 图片与视频混合成片

1. 读 [本机入口](references/runtime.md)、[命令](references/commands.md)、[项目格式](references/project-format.md)。只有明确顺序的现成图音也可以建立项目后直接合成，不虚构旁白或分镜。
2. 导入实际媒体，读取尺寸、时长及音轨情况。按 [时间与声音](references/timeline.md) 为每镜确定实际窗口和音轨策略。
3. 从已选素材形成清单，字段与示例见 [合成清单](references/manifest.md)。图片与视频可以混排；参考素材不自动作为成片素材。
4. 需要先了解实际合成安排时运行 `ntf compose PROJECT --manifest FILE --plan-only`；确定的清单执行同命令而不带该选项。
5. 通过工作流合成时执行对应 compose 动作。缺少素材时返回具体镜头与所需内容，由编排安排生成，不自行递归重做整条视频。
6. 保留旧输出，取得本次 MP4、时间表和字幕等实际文件。观看输出、确认预期镜头和音轨确实存在，再报告成片位置。

视频短于讲述时必须有明确补画面、定格、追加片段或改稿方案，不默认截掉旁白。只输出计划、命令或静音占位文件不算完成成片。
